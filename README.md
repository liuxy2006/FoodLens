# FoodLens

神经网络与深度学习课程设计。

## 项目任务

1. 食物图像描述生成
2. 食物图像到结构化膳食记录
3. LLM-as-Judge 评价
4. 单图像营养估计

## 项目结构

- `data/`：数据集说明和数据处理
- `task1_caption/`：食物图像描述生成
- `task2_diet_record/`：结构化膳食记录生成
- `task3_llm_judge/`：LLM-as-Judge
- `task4_nutrition_estimation/`：单图像营养估计
- `evaluation/`：BLEU、CIDEr、F1、MSE 等指标
- `app_or_demo/`：统一演示入口
- `configs/`：模型和实验配置
- `docs/`：开题、中期和结题资料
- `tests/`：测试代码

## 小组分工

- 成员 A：数据处理、任务一模型 A
- 成员 B：任务一模型 B、LLM-as-Judge
- 成员 C：任务二、单图像营养估计
